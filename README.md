## Développement

```bash
git clone https://github.com/LUST-DEV/lust-dev-portfolio.git
cd lust-dev-portfolio
pnpm install --frozen-lockfile
pnpm run dev
```

Le build et les types se vérifient avec `pnpm run build` et `pnpm run check`.
