## Installation locale

Pré-requis : Node.js 22 ou version compatible et pnpm 10.

```bash
git clone https://github.com/LUST-DEV/lust-dev-portfolio.git
cd lust-dev-portfolio
pnpm install --frozen-lockfile
pnpm run dev
```

### Contrôles locaux

```bash
pnpm run check
pnpm run build
pnpm audit --prod
```

## Variables d’environnement

Les variables sont documentées dans [`.env.example`](.env.example). Ne publie jamais les valeurs privées dans GitHub.

| Variable | Type | Usage |
|---|---|---|
| `VITE_GA_MEASUREMENT_ID` | Publique | Google Analytics 4, après consentement cookies. Valeur configurée : `G-HD46DQXB9H` |
| `VITE_RECAPTCHA_SITE_KEY` | Publique | Site key reCAPTCHA, uniquement lorsqu’un formulaire est ajouté |
| `RECAPTCHA_SECRET_KEY` | Privée serveur | Secret reCAPTCHA, jamais dans le frontend |
| `VITE_FRONTEND_FORGE_API_KEY` | Publique restreinte | Carte éventuelle, à limiter par domaine |
| `VITE_FRONTEND_FORGE_API_URL` | Publique | URL du proxy Maps |
| `VITE_APP_ID` | Publique | Identifiant OAuth éventuel |
| `VITE_OAUTH_PORTAL_URL` | Publique | Portail OAuth éventuel |

Dans Vercel : **Project → Settings → Environment Variables → Add New**. Pour Analytics, le nom exact est `VITE_GA_MEASUREMENT_ID`, pas `GA_MEASUREMENT_ID`.

## Déploiement avec Vercel

1. Ouvre [Importer le projet dans Vercel](https://vercel.com/new/clone?repository-url=https://github.com/LUST-DEV/lust-dev-portfolio).
2. Sélectionne `LUST-DEV/lust-dev-portfolio`.
3. Utilise :

```text
Framework Preset: Vite
Install Command: pnpm install --frozen-lockfile
Build Command: pnpm run build
Output Directory: dist/public
Production Branch: main
```

Chaque push sur `main` déclenche le déploiement Vercel. Aucun VPS n’est nécessaire.

## Indexation Google

Le site public est : [lust-dev-portfolio.vercel.app](https://lust-dev-portfolio.vercel.app/).

Les signaux SEO actifs sont :

- `robots.txt` avec sitemap Vercel ;
- sitemap XML sur le domaine canonique ;
- canonical URL Vercel ;
- Open Graph et Twitter Card ;
- image sociale PNG ;
- données structurées `WebSite` et `Person` ;
- balise Google Search Console.

Pour demander l’indexation :

1. ouvre [Google Search Console](https://search.google.com/search-console/about) ;
2. ajoute la propriété URL prefix `https://lust-dev-portfolio.vercel.app/` ;
3. vérifie la propriété avec la balise déjà présente ;
4. ouvre **Inspection de l’URL** ;
5. saisis `https://lust-dev-portfolio.vercel.app/` ;
6. clique sur **Demander une indexation** ;
7. dans **Sitemaps**, ajoute `sitemap.xml`.

L’indexation dépend ensuite du crawl de Google et ne peut pas être garantie instantanément par le dépôt seul.

## Sécurité et confidentialité

- dépendances de production auditées avec `pnpm audit --prod` ;
- aucun secret réel commité ;
- CSP, HSTS, `X-Frame-Options`, `nosniff` et Referrer Policy ;
- cookie de consentement `SameSite=Lax` et `Secure` sous HTTPS ;
- Analytics et reCAPTCHA différés selon le consentement ;
- rate limiting et détection de payloads suspects préparés côté Express ;
- aucun formulaire, endpoint SQL, compte admin ou base de données actuellement exposé.

Les détails sont disponibles dans [la documentation confidentialité et reCAPTCHA](docs/privacy-and-recaptcha.md).
